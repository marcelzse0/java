Pętla for

Konstrukcja:
for (inicjalizacja; warunek; zmiana) { kod }

Opis: Wykonuje kod określoną liczbę razy.

Pętla while

Konstrukcja:
while (warunek) { kod }

Opis: Wykonuje kod, dopóki warunek jest prawdziwy.

Pętla do...while

Konstrukcja:
do { kod } while (warunek);

Opis: Kod wykona się przynajmniej raz, warunek jest sprawdzany po wykonaniu kodu.
